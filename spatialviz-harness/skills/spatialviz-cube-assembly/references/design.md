# Cube Assembly design record

Use `two-parts` or `three-parts` for deletion foils, `equal-three` for a three-piece volume tie, and `interface` or `relocated` for the handed pair. Set `arm` from 2 to 5 and set `none` to true to withhold the winning piece. The seed selects the arm length when omitted and permutes A/B/C.

Deletion foils occur in the released builder. Some released images also have equal-count foils. The new directed interface pair supplies explicit layer maps, a movement contract and proper-rotation packing witnesses.
