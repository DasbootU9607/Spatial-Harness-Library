## Multi-arrow path and state, seed 581

1. `create_arrow_moving_complex.py:main` creates an `ArrowMap`, fills cells probabilistically from a palette with replacement, draws an arrow and legal relative displacement per step, and repeats from the same board for three alternative endpoints. Input was a 3 by 3 board, two moves and one sample. `plot_map` makes a Matplotlib panel for the start and each end. Allocate the named sample subdirectory before calling this main. Its first `savefig` otherwise precedes directory creation.
2. In the printed start, green points west at (1,2), yellow north at (1,1), red south at (0,0), and purple east at (2,0). Taking green left two moves south to (1,0). Yellow is an intermediate cell and stays there. Taking red backward one moves north to (0,1) and reverses its facing. The target contains both of those new poses; yellow and purple are unchanged.
3. `generate_data.py` dispatches `prepare_composite_image_ArrowMoving_complex(dir_path, mode=0)`. Pillow labels the start/end pair. Seed 19 assigns B to the path above. A shares the first move, then exchanges green with purple, leaving red at (0,0). C first overshoots red to (0,2) and moves yellow. D advances green only one and then exchanges purple with red. All four sequences run from the printed start. Hash of the 1794 by 1050 PNG is `637a07e5866973faa443ac7a75d9ba9d49606b722c8e716b12b2bc748dceef6b`.

## Execution details

The dispatcher ships with a placeholder folder and commented task calls. The probe activated its selected line, skipped imports for unrelated task families, used a platform-native join for the metadata path and resolved the repository's DejaVu Sans Bold font by full path. The model and motion routines were unmodified. The complex modes ran in separate folders because state mode renames option files. Raw generation, option shuffle and drawing have separate roles. A sampled alternative that differs from the official terminal state can still duplicate another alternative, so compare all four as displayed.

The private reproducibility index is `.harness/animation/native-probes` in the checkout. It contains `probe.py`, one receipt per mode, raw PNGs, paths, dispatch records and model logs. From the repository root in a fresh probe output directory, the native probe commands are `python -B .harness/animation/native-probes/probe.py single`, `paths` and `states` (replace the final argument). For published items use the maintained skill commands.
