# Native generation and publication

SpatialViz-Bench uses FreeCAD in its released programmatic generation workflows. The authors describe the Mechanical System set as expert-designed from public simulation references. The pinned public archive c27f9111a2674f2ea03e2ca1f5833326cf1eec1a has no Mechanical System model generator or confirmed original drawing application. The released evaluation path reads the original media, choices and keys. Its image and prompt stages were exercised on all 80 items during the audit. [Official project](https://wangst0181.github.io/SpatialViz-Bench/) · [Paper](https://openreview.net/pdf?id=OqZ7bm28Xx)

Use Node 20+, Python with Pillow and NumPy, and a FreeCAD GUI executable with the PartDesign involute gear feature. `SPATIALVIZ_PYTHON` selects the outer Python and `SPATIALVIZ_FREECAD` selects FreeCAD. The tested native runtime was 1.0.2 on Windows. The package uses the [native authoring format](freecad-authoring.md).

From the package directory, run `node scripts/read-native.cjs FINAL.png` for a standalone reading of the printed conditions and all four options. Its only question-specific input is the actual PNG.

The build prints paths to the final PNG, task, FCStd, native working directory and recorder. Keep failed candidates. The bound verifier launches a second FreeCAD process to reopen the exact document and remeasure its interfaces. It also recomposes the labeled PNG from the native captures, compares the published conditions with measured joints and tests each text option. Colored body labels in the front view use temporary native registration markers. The clean source views and saved FCStd contain the assembly.

For a visual correction, rebuild in the same recorder run with `--parent` and `--basis`. Record `node scripts/construct.cjs review --run RUN --candidate ID --outcome passed --review "Specific observations"`. Finish with `node scripts/construct.cjs finish --run RUN --candidate ID --task TASK --local-only`, then use the library publisher with the run, task and package path. Publication checks the model and view hashes and ships the two source views, FCStd, authored parameters and geometry report beside the final picture. The skill page has an expandable history of earlier SVG tasks and their builds.

Run the package tests from the root with `node --test spatialviz-harness/skills/spatialviz-mechanical-system/scripts/*.test.cjs`. The native trial requires the GUI runtime. The tests for the previous [goal-led worksheet trials](author-trials.md) protect historical reading and reproduction. Formal publication uses the native adapter.
