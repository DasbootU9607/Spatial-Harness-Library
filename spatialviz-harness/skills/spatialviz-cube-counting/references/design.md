# Cube Counting design record

Use `min-2`, `min-3`, `max-2`, `max-3`, `possible-2` or `possible-3`. Set `size` from 2 to 4 for the footprint and `none` to true for a fallback answer. `exact-2` deliberately emits the ambiguous diagnostic. `exact-3` adds the resolving left elevation.

The release asks for extrema or a possible value. New exact-count diagnostics use the same orthographic evidence. The checker measures feasible totals independently of the original native stack.
