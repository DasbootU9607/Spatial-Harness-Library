# SpatialB Harness

A planned authoring harness for procedural path tracing and voxel rotation tasks.

**Status** · Under construction

## Source

[SpatialBench](https://github.com/spicylemonade/spatialbench) is the upstream project for this harness. Follow 2D paths and compare 3D shapes from different viewpoints.

The library preview is a screenshot of a 20-node path-tracing exercise rendered by the [upstream interactive practice game](https://spicylemonade.github.io/spatialbench/). The game generates a fresh practice question each time.
