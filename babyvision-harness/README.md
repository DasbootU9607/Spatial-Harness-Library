# BabyVision Harness

A planned authoring harness for visual reasoning tasks with written answers or annotated images.

**Status** · Under construction

## Source

[BabyVision](https://github.com/UniPat-AI/BabyVision) is the upstream project for this harness. Explore visual puzzles about patterns, fine details and paths.

The library preview shows the original input image for visual discrimination task 445 from [the BabyVision dataset](https://huggingface.co/datasets/UnipatAI/BabyVision/tree/849cbeea2b1d00ad334e9e1e2b49a1960c9ff3f3).
